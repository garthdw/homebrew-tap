# homebrew-tap

Personal Homebrew tap for [garthdw](https://github.com/garthdw)'s CLI tools.

## Usage

```bash
brew tap garthdw/tap
brew install garthdw/tap/<formula>
```

Or install directly without tapping first:

```bash
brew install garthdw/tap/<formula>
```

## Formulas

Formulas in this tap are published automatically by [GoReleaser](https://goreleaser.com/) from each project's own release workflow. Don't edit files in `Formula/` by hand — they're regenerated on every release.
